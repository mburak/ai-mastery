Most of the engineers I've watched grow from junior to senior did it the same way. They wrote a lot of code, broke a lot of code, and slowly built mental models from the pieces. The typing wasn't incidental to the learning. It was the learning.

<!--more-->

I spent fourteen of my twenty-seven years in management. I watched maybe two hundred engineers go through some version of this path. The good ones came out the other side with the kind of intuition you can't fake. Not because they were special, but because they put in the hours typing, failing, debugging, and rewriting.

That mechanism is broken.

I noticed it most clearly in a code review a few weeks ago. The engineer had shipped a working refactor. The code did what it was supposed to do. But when I asked why it was structured that way, the answer was some version of "that's what the model produced." They could describe what the code did. They couldn't say why it was written that way.

The feedback loop that used to force understanding — your code won't compile, your test fails, your function returns nothing — is now mediated by a model that produces working code on the first or second try. You can ship for months without ever building a real mental model.

**You can look competent without being competent. That's a new failure mode.**

The skills that built themselves automatically — debugging from first principles, reading unfamiliar code, holding a system in your head — came from forced exposure. You had no choice but to read, debug, and trace, because there was no faster way. AI made all of that optional.

What needs to be deliberate now wasn't deliberate before. Juniors have to choose to understand. They have to read the diff carefully, explain functions back, debug things themselves rather than ask the model. None of that happens by default anymore. Shipping faster usually wins.

I don't think AI is going to stop juniors from becoming seniors. But it won't happen on autopilot the way it used to. What used to be the automatic outcome of writing code for five years is now the result of deliberately choosing to understand it.

The typing was the lesson. Now the choice is.
